# Test list: new interactions (v0.28.147, issue #49)

Visible only with the **Prüfer** or **Entwickler** role. In the app, the topics are titled "… · Neu (Prüfung)".
The new interaction shows up as one variant among several in the topic, so a round contains it a few times, not in every task. Practise each topic **at least 2 rounds**.

For each topic, check: operation on desktop **and** phone/tablet (touch), correct check (right → green, wrong → red), explanation/solution matches the picture, nothing given away in the task text, worksheet print.
