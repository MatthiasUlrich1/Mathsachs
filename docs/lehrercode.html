{{TEACHER_CODE}}

Ein Code für alle Lehrer und Klassenlehrer der Schule

Wofür der Code ist

Mit diesem Code kannst du in Mathsachs die Rolle Lehrer oder Klassenlehrer anlegen oder übernehmen. Ohne den Code können Schülerinnen und Schüler sich nicht als Lehrkraft eintragen und keine Klassen- oder Stufencodes anlegen.

So trägst du den Code ein

  1. Mathsachs öffnen (Desktop-App oder im Browser).
  2. Beim Anlegen eines Benutzers Lehrer oder Klassenlehrer wählen — oder später unter Einstellungen → Profil die Rolle wechseln.
  3. Diesen Lehrercode eingeben: {{TEACHER_CODE}}
  4. Im Profil steht derselbe Code. Du kannst ihn an weitere Lehrkräfte der Schule weitergeben.
Nicht an Schülerinnen und Schüler weitergeben. Der Code ist nur für Lehrkräfte. Wer ihn kennt, kann Stufen und Klassen anlegen.
Auf dem Klassen-Server werden dazu keine Personendaten gespeichert. Der Lehrercode liegt nur in der App und auf diesem Blatt.
